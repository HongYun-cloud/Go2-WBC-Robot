## 目标

在 `SwingLegPlanner.cpp` 中完成你描述的摆动轨迹重构：**x 用三阶贝塞尔（全周期 T），z 用五阶贝塞尔、分 z_up/z_down 两段拼接（前 0.5T 上升、后 0.5T 下降）**，x 与 z 合并为一个 Point 输出。当前代码处于半成品状态（`Generate()` 中 `p/v/a` 未定义，编译不过；z 两段未按相位选择；`Bezier_Math` 无五阶分支）。

## 已确认的设计决策

- y 轴：保持抬腿前足端 y 不变，v_y = a_y = 0（不做 Raibert）。
- 步高自适应公式更新为 min-jerk 峰值加速度口径：`Walk_H = min(0.15, 15·T_swing²/23.09)`（23.09 = 4×5.7735，min-jerk 半周期峰值系数），T_swing=0.25s 时 H≈0.04m，保持垂直加速度 ≤15 m/s²。
- z_down 落地高度恢复旧版世界系地面高度 **0.023**（当前 WIP 写的 0.0 是笔误）。

## 修改内容

### 1. `Bezier_Math` 增加五阶分支（mid.size()==4，即 6 控制点）
在 `evaluatePos / evaluateVel / evaluateAcc` 各加一个 `degree == 4` 分支，按一般 Bernstein 形式展开：
- pos：`Σ C(5,i)(1-t)^(5-i)·t^i·P_i`
- vel：`5·Σ C(4,i)(1-t)^(4-i)·t^i·(P_(i+1)−P_i)`
- acc：`20·Σ C(3,i)(1-t)^(3-i)·t^i·(P_(i+2)−2P_(i+1)+P_i)`

### 2. 控制点定义（liftoff 时，构造函数/Reset 同步改为新格式）

- **x（三阶，全周期，端点速度为零）**：沿用你 WIP 中的写法——`Start = 足端x`，`Mid = [S, E]`，`End = p_hip.x + ½T_stance·v_x + k·(v_x−v_des.x)`（含不落后于髋部的钳位）。
- **z_up（五阶 min-jerk）**：`Start = 足端z`（世界系），`Mid = [S, S, S+H, S+H] + offset.z`，`End = S+H+offset.z` —— 两端速度、加速度均为零，与 z_down 在顶点处 C2 连续。
- **z_down（五阶 min-jerk）**：`Start = S+H+offset.z`，`Mid = [S+H, S+H, E_g, E_g]`，`End = E_g = 0.023`（世界系地面高度，同旧版）。

### 3. `Generate()` 求值与拼接

```
if (t < 0.5)  τ = 2t        → 用 z_up 求值
else          τ = 2t − 1    → 用 z_down 求值
```

时间量纲缩放（z 段局部时长为 T/2，相位速率是 x 的 2 倍）：
- z 速度求值后 ×2、加速度求值后 ×4；
- x 速度保持相位量纲（消费端 `GetSwingVel()/T_swing` 的现有约定不变），x/z 加速度统一在规划器内 `/T_swing²`（与现状一致）。

### 4. 合并为 Point + 收尾

- liftoff 边沿把 `_foot_pos.row(leg).y()` 存入新成员 `std::array<double,4> _swing_y`（头文件加这一个成员）；摆动期输出 `p = (p_x, _swing_y[leg], p_z)`、`v = (v_x, 0, v_z)`、`a = (a_x, 0, a_z)`。
- 支撑期 `t==0`：不再用曲线起点的陈旧值覆盖 `_foot_pos`，保持 FK 反馈值，v/a 置零（保留现有置零逻辑）。
- 修正 WIP 中的编译错误（`p/v/a` 未定义、`a = a/(T²)` 位置、`a_X` 拼写），删除第 137 行错位的除法并移到合并之后。
