在工作区根目录创建 `clean.sh`,用于删除 colcon 编译缓存。

**脚本内容**(删除顶层与 go2/ 下的 build、install、log 共 6 个目录,删除前打印占用,删除后确认;支持 `--dry-run` 预览):

```bash
#!/usr/bin/env bash
# clean.sh — 清理 ROS2 colcon 编译缓存 (build / install / log)
# 用法: ./clean.sh [--dry-run]
set -euo pipefail
cd "$(dirname "$0")"

dirs=(build install log go2/build go2/install go2/log)

echo "清理前磁盘占用:"
du -sh "${dirs[@]}" 2>/dev/null || true

if [[ "${1:-}" == "--dry-run" ]]; then
    echo "(dry-run 模式,未执行删除)"
    exit 0
fi

for d in "${dirs[@]}"; do
    rm -rf "$d"
done

echo "清理完成。如需重新编译: colcon build --packages-select go2_robot"
```

**说明**:
- `install/` 是占用大头(92M),三个目录合计约 133M。
- 不动 `MUJOCO_LOG.TXT`、`go2/MJDATA.TXT`、`go2/mjmodel.mjb` 等 MuJoCo 运行时生成文件(它们不是编译缓存;如果也想清理可以再加)。
- 创建后用 `chmod +x clean.sh` 赋予执行权限。

**执行步骤**:
1. 写入 `/home/hong/Movement_Control/Go2Robot/clean.sh`
2. `chmod +x` 赋权
3. 默认不执行删除,由你自己运行 `./clean.sh`(或先 `./clean.sh --dry-run` 预览)
