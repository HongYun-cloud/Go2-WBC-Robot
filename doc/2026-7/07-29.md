### 2. 遇到问题
1. 当下界为20的时候足端计算为23,23,20,20，修改下界以后变成0,0,0,0，所以他计算的结果总是0
2. mpc正确计算足端力，但是到关节上cout发现为0，输出雅克比发现为0

### 3. 解决方案
1. 原R的参数为1,导致控制代价比较高，可能不是这个问题但是是一个潜在的问题
2. z的坐标原来是-0.2,现在改成了0.1,这个是主要问题，应为这个坐标系是世界坐标系，我把他当成了狗坐标系了，下次写的时候需要注意
3. 接触腿 controller->data->est_state.contact_states是一个4元素的数组，但是在mpc中有预测，所以需要扩充为contact_expanded，否则在regulator.h中填充QP的A，U和上下界会return
4. 还有个需要注意的点，最小值为非负数，具体回忆摩擦锥
5. 因为我是使用pinocchio来处理每个关节的映射关系的，而输出雅克比是０说明pin没有计算雅克比，查询ai得知需要调用computeJointJacobians()来计算出映射关系，函数介绍如下

        pinocchio::computeJointJacobians(model, data, q)
        全量雅可比矩阵保存在　data.J
        可以使用如下提取雅克比

        pinocchio::getJointJacobian(
        model, 
        data, 
        joint_id,                            // 你想看的关节 ID
        pinocchio::ReferenceFrame::LOCAL,    // 坐标系参考 (LOCAL, WORLD, 等)
        J_leg                                // 结果会写入这个矩阵
        );
