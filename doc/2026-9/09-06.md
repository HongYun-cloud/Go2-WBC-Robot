# 2026-9-6 修改记录：WBC 摩擦锥约束解决姿态振荡

## 问题背景

尽管在 SwingLegPlanner 和 `computePoseAccDes` 中修复了坐标系问题并恢复了PD增益，机器人仍存在持续的roll/pitch振荡。通过PlotJuggler分析发现，WBC的tau_pitch_wbc和tau_roll_wbc与MPC的对应值几乎完全重合，说明PD控制器在力分配阶段被架空，无法有效调整姿态。

## 根本原因分析

通过PlotJuggler可视化诊断，确认问题在于：
1. **力通道PD失效**：tau_pitch_mpc与tau_pitch_wbc完全重合，说明WBC严格跟踪MPC接触力，没有为姿态PD提供力分配自由度
2. **QF权重不平衡**：MPC配置中力跟踪权重FI=100过高，导致QP优先满足接触力跟踪而非动力学约束
3. **无物理约束**：原WBC无摩擦锥约束，QP可生成任意方向的接触力，导致不现实且不稳定的分配

## 技术方案

### 1. QP权重调整 (config/mpc.yaml)

**力跟踪权重FI从100降至10：**
```yaml
# 跟踪 MPC 力代价权重 (12 维对角), f → f_des
FI: [10, 10, 10,
     10, 10, 10,
     10, 10, 10,
     10, 10, 10]
```

**动力学约束权重C从10提升至100：**
```yaml
# 摆动腿跟踪 + 基座动力学软约束权重 (30 维对角)
C: [200, 200, 200, 200, 200, 200, 200, 200, 200, 200, 200, 200,
    100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100, 100,
    100, 100, 100, 100, 100, 100]
```

**修改效果：**
- FI降低使力跟踪从"硬约束"变为"软参考"
- C提升确保QP解满足动力学关系：M·a ≈ Jᵀ·f - h
- 为姿态PD控制器提供真正的力分配自由度

### 2. 摩擦锥约束实现 (src/WBC/WBC_Base.h & src/WBC/WBC.cpp)

**扩展QP约束维度：**
```cpp
class QPConstraint {
public:
    std::vector<Eigen::Triplet<double>> A;  // 约束矩阵行数从30→50
    Eigen::VectorXd lb, ub;                 // 约束上下界
    // ... 原有成员
};
```

**添加摩擦锥约束 (updateconstraint函数)：**
```cpp
// 每条腿添加4个摩擦锥约束，共4腿×4=16行
// |fx| ≤ μ·fz
qpconstraint->A(row,     col)     =  1.0;  qpconstraint->A(row,     col + 2) = -mu;
qpconstraint->A(row + 1, col)     = -1.0;  qpconstraint->A(row + 1, col + 2) = -mu;
// |fy| ≤ μ·fz  
qpconstraint->A(row + 2, col + 1) =  1.0;  qpconstraint->A(row + 2, col + 2) = -mu;
qpconstraint->A(row + 3, col + 1) = -1.0;  qpconstraint->A(row + 3, col + 2) = -mu;
// fz ≥ 0 (已包含在原有约束中)
```

**关键参数：**
- 摩擦系数 μ = 0.5 (与MPC QPConstraint保持一致)
- 每条腿4个约束：|fx| ≤ μ·fz, |fy| ≤ μ·fz, fz ≥ 0
- 总约束数：50行 (基础30行 + 摩擦锥20行)

### 3. 增益恢复与诊断 (src/ros2/go2_control_node.cpp)

**恢复computePoseAccDes中的PD增益：**
```cpp
Eigen::Vector3d Kp_ang(50, 50, 30);   // 从(3,3,3)提升到有作用量级
Eigen::Vector3d Kd_ang(10, 10, 5);   // 从(0.5,0.5,0.5)提升
```

**新增摩擦锥与力矩诊断字段：**
```cpp
// 偏航力矩诊断
tau_yaw_mpc = Σ(r × f_mpc)
tau_yaw_wbc = Σ(r × f_wbc)

// 摩擦锥利用率 (0-1, >1表示打滑)
f_cone_* = |ft|/(μ·fz)
```

**签名修改：**
```cpp
void fillTelemetryMessage(..., const Eigen::Matrix<double,12,1>& f_mpc,
                                const Eigen::Matrix<double,12,1>& f_wbc, ...);
```

## 修改效果预期

### 1. 姿态恢复机制
- FI权重降低后，tau_pitch_wbc应开始偏离tau_pitch_mpc
- 偏离方向与q_des_ang_y相关，表明PD控制器重新获得力分配权限
- roll/pitch振荡幅值应显著降低

### 2. 物理约束验证
- f_cone_*应大部分时间<1，避免足端打滑
- 极端情况下可能出现>1，需要进一步调参或约束 tightening
- 摩擦锥约束确保接触力在物理可实现范围内

### 3. 稳定性提升
- 动力学约束权重提升确保Q解满足实际机器人动力学
- 摩擦锥约束防止足端打滑引起的姿态失控
- PD控制器在约束范围内提供必要的姿态纠偏

## 后续调参方向

1. **FI权重微调**：如果仍有振荡，可继续降低FI (5→10→2)
2. **PD增益调整**：基于观察效果，可小幅调整Kp_ang(50,50,30)
3. **摩擦系数调整**：若打滑明显，可降低μ (0.4→0.5→0.6)
4. **约束权重平衡**：确保C在100附近保持足够权重

## 验证方法

重启节点与PlotJuggler，观察以下指标：
1. tau_pitch_wbc/tau_roll_wbc开始偏离对应MPC值
2. f_cone_*维持<1，无持续打滑
3. roll/pitch偏差显著减小，振荡基本消除

通过这一系列修改，WBC同时考虑了物理约束和动力学一致性，为姿态PD提供了真正的控制自由度，解决了持续roll/pitch振荡的根本问题。
