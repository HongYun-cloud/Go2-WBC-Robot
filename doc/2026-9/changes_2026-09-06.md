# Git 提交记录 - 2026年9月6日

## 提交摘要
本次提交主要涉及ROS2版本的四足机器人控制系统的重大更新，包括新增Go2Telemetry遥测消息、优化WBC控制系统、改进控制节点以及更新配置文件等。

## 主要改动详情

### 1. 新增Go2Telemetry遥测消息 (msg/Go2Telemetry.msg)
- **功能**: 为PlotJuggler提供遥测数据可视化支持
- **字段设计**: 
  - 摆动轨迹参考/实际足端位置 (FL, FR, RL, RR × x, y, z)
  - 摆动轨迹参考/实际足端速度
  - 摆动轨迹参考/实际足端加速度
  - MPC/WBC足端接触力
  - 计划接触状态
  - 机身位置/速度信息
  - WBC期望加速度 (基座线3 + 角3 + 关节12)
  - 诊断信息: 偏航力矩、摩擦锥利用率、roll/pitch力矩等

### 2. WBC系统优化 (src/WBC/WBC.cpp, include/WBC/WBC.hpp)
- **配置加载**: 完善了WBC配置文件的加载逻辑
- **目标函数优化**: 改进了18维基座状态和12维关节力的权重矩阵配置
- **约束处理**: 优化了30维约束矩阵的初始化
- **性能提升**: 改进了WBC计算效率和稳定性

### 3. 控制节点更新 (src/ros2/go2_control_node.cpp, include/ros2/go2_control_node.hpp)

- **内存管理**: 改进了对象的生命周期管理，防止内存泄漏

### 4. 配置文件更新 (config/mpc.yaml)

## 技术特点

### 1. 坐标系一致性
- 所有足端数据均使用世界坐标系
- 机身位置和速度使用世界坐标系
- 角速度使用机身坐标系
- 确保了数据的一致性和可解释性

### 2. 控制架构
- **主循环频率**: 500Hz (与MuJoCo时间步长一致)
- **MPC频率**: 100Hz (异步计算)
- **发布频率**: 50Hz (状态发布)
- 分层控制架构：MPC → WBC → 关节控制

### 3. 诊断功能
- 添加了完整的诊断信息输出
- 包括摩擦锥利用率、力矩平衡等关键指标
- 便于系统监控和故障诊断
